# Forker 0.1.3

Forker 0.1.3 is a preview release focused on updater support, resizable workbench panes, quieter refresh behavior, and core workflow hardening.

## Highlights

- Forker can now check for signed desktop updates from GitHub Releases in packaged builds.
- Workbench panes can be resized and restored across sessions.
- Background repository refreshes are less disruptive during review.
- Git operation feedback, empty states, and error guidance are clearer.
- Accessibility and Git operation safety coverage were improved.

## Added

- Signed app update checks and install/restart flow in Settings.
- Passive update awareness in the sidebar for packaged desktop builds.
- Resizable repository sidebar, changed-file list, and commit details pane.
- Keyboard-operable resize separators with reset-on-double-click behavior.
- Lightweight Git operation feedback for small file-level actions.
- Documentation for signed updater release artifacts.

## Changed

- Background repository refreshes are quieter and avoid interrupting active review work where possible.
- Selected files and commits are preserved more reliably across refreshes.
- Empty states and Git-not-found/error guidance now explain next steps more clearly.
- Dialog, command palette, file list, and commit log keyboard paths were hardened.

## Fixed

- Added/expanded safety tests for branch, remote, reset, discard, stash, and push workflows.
- Reduced refresh-related selection churn in common review contexts.

## Known issues

- Forker requires a working system `git` executable; Git is not bundled.
- Updater packages require release-time Tauri signatures generated by GitHub Actions with the owner-held signing secrets.
- Some complex keyboard and screen-reader interactions may still need follow-up hardening.
- Merge-conflict editing, interactive rebase, worktree management, submodule management, and hosting-provider integration remain out of scope for this release.
- macOS and Windows public distribution still need owner-specific signing/notarization validation.
