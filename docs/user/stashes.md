# Stashes

Status: Current

A stash saves uncommitted changes so you can return to a clean working tree or switch context.

## Create a stash

Use the stash action from the toolbar or command palette. Review the confirmation if the action will move changes out of the working tree.

## Future stash support

Richer stash browsing and apply/pop/drop flows are planned after the core working-tree and branch workflows are stable.

## Safety note

Stash operations affect uncommitted work. Read the dialog copy and confirm the affected files before continuing.
