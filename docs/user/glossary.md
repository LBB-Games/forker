# Glossary

Status: Current

## Ahead

Your branch has local commits that have not been pushed to its upstream branch.

## Behind

The upstream branch has commits that your local branch does not have.

## Commit

A saved snapshot in Git history.

## Dirty working tree

The repository has uncommitted changes.

## Fetch

Download remote refs and objects without integrating them into the current branch.

## Pull

Fetch and integrate remote changes into the current branch.

## Push

Send local commits to a remote branch.

## Ref

A Git name that points to a commit, such as a branch or tag.

## Remote

A named external repository, commonly `origin`.

## Staged

Included in the next commit.

## Unstaged

Changed locally but not included in the next commit.

## Untracked

A file Git does not track yet.

## Working tree

The checked-out files in your repository directory.
