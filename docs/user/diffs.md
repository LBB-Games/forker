# Diffs

Status: Current

Forker displays unified diffs for changed files and selected commits.

## Read a diff

- Green rows indicate additions.
- Red rows indicate deletions.
- Hunk headers show the changed region.
- Line numbers show old and new file positions where available.

Color is paired with row shape/text so state does not rely on color alone.

## Long lines

Diff content should remain readable and must not be hidden by ellipsis. Use horizontal scrolling for long lines.
